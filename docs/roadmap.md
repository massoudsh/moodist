# نقشه راه Moodist

## فاز ۱ — MVP
- کتابخانه اولیه صداهای محیطی (چند دسته: Nature, Rain, Urban, Noise)
- میکسر پایه: play/pause و ولوم مستقل هر صدا با fade نرم

## فاز ۲ — اشتراک‌گذاری و Preset
- ذخیره/تغییرنام/حذف presetها در localStorage
- اشتراک‌گذاری mix از طریق URL (encode/decode state)

## فاز ۳ — ابزارهای تمرکز
- تایمر Pomodoro، sleep timer، countdown
- تمرین تنفس (breathing exercise)
- Notepad و Todo ساده

## فاز ۴ — PWA
- manifest + service worker برای نصب و کارکرد آفلاین

## فاز ۵ — صدای پیشرفته و توزیع
- تولید binaural beats و isochronic tones
- پکیج Docker برای self-host
- بومی‌سازی (فارسی/انگلیسی)

> هر فاز مستقل قابل تحویل است؛ فاز بعدی به تکمیل کامل فاز قبل وابسته نیست مگر جایی که صریحاً ذکر شده.
