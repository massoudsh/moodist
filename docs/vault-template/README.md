# Vault Template

قالب آماده‌ی «ویکی دانش پروژه» — همان سیستمی که خودِ این ریپو (Moodist) برای نگه‌داری ویکی دانش
داخلی‌اش استفاده می‌کند، به‌صورت عمومی و مستقل برای استفاده در هر پروژه‌ی دیگر بسته‌بندی شده.

## استفاده در یک پروژه‌ی جدید
1. پوشه‌ی `wiki/` این قالب را داخل پروژه‌ی جدید کپی کن (پیشنهاد: `docs/wiki/`).
2. محتوای `RECIPE.md` را به‌طور کامل کپی کن و در ابتدای فایل `CLAUDE.md` یا `AGENTS.md` همان پروژه
   (یا هر جای دیگری که system prompt پروژه را می‌سازد) پیست کن.
3. از سشن بعدی، ایجنت خودش طبق قوانین `RECIPE.md` صفحات `overview.md` و `index.md` را می‌خواند،
   و بعد از هر تغییر معنایی در کد، ویکی را به‌روز نگه می‌دارد.

## محتوای این قالب
- `RECIPE.md` — متنی که باید کپی/پیست شود (دستورالعمل کامل برای ایجنت).
- `wiki/schema.md` — قوانین کامل ساختار و لینک‌گذاری (خودِ ایجنت بعداً آن را برای هر پروژه دقیق‌تر می‌کند).
- `wiki/overview.md`, `wiki/index.md`, `wiki/log.md` — اسکلت خالی با placeholder.
- `wiki/entities/`, `wiki/concepts/`, `wiki/sources/` — پوشه‌های خالی آماده برای صفحات آینده.

## چرا اینجاست
این قالب کد یا رفتار Moodist را تغییر نمی‌دهد؛ فقط یک آرتیفکت مرجع/قابل‌استفاده‌مجدد است که کنار
ریپو نگه‌داری می‌شود تا در پروژه‌های آینده دوباره از صفر نوشته نشود. با رشد و پختگی بیشتر سیستم ویکی
در این ریپو، همین‌جا هم به‌روز می‌شود.
