# Schema

قوانین ساختار و لینک‌گذاری ویکی این پروژه. این فایل را برای پروژه‌ی مقصد دقیق‌تر/سفارشی کن.

## نام‌گذاری فایل‌ها
- lowercase + hyphen، مثلاً `user-model.md`, `auth-flow.md`.
- بدون فاصله، بدون کاراکتر خاص.

## لینک‌ها
- سبک Obsidian: `[[entities/user]]` — بدون پسوند `.md`.
- هر صفحه‌ی جدید باید حداقل از یک صفحه‌ی دیگر (معمولاً `index.md`) لینک بخورد؛ صفحه‌ی orphan ممنوع.

## انواع صفحه
- `entities/*.md` — یک واحد ملموس از کد (مدل، سرویس، روتر، صفحه‌ی کلیدی UI).
- `concepts/*.md` — یک ایده/جریان/قرارداد که چند entity را به هم وصل می‌کند.
- `sources/*.md` — (اختیاری) خلاصه‌ی فایل خام کدی که پرارجاع است.

## آستانه‌ی ساخت صفحه‌ی جدید
فقط وقتی:
- حداقل ۳ جای دیگر قرار است به آن لینک بدهند، یا
- concept/entity به‌قدر کافی مستقل و حجیم است که در صفحه‌ی پدر نگنجد.

در غیر این صورت، به‌جای صفحه‌ی جدید، صفحه‌ی موجود را با یک section/paragraph به‌روز کن.
